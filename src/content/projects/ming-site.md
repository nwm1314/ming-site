ming-site 是这个个人主页本身。它用 Astro、TypeScript 和 CSS 生成静态页面，内容按 Markdown collections 维护；目前优先完善首页、Blog、Projects、Now、Uses 和搜索等基础体验。

它的首要目标不是“看起来像一个完整产品”，而是让未来的内容有一个舒服、可维护的家：页面保持轻量，路由保持清楚，写下来的东西能在下一次打开时继续工作。
